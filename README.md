# NextBites

A recipe discovery website built using Next.js, TypeScript and CSS.

## Features

- Responsive recipe card grid
- Reusable typed RecipeCard component
- Centralised recipe data
- Shared navigation layout
- Cuisine, preparation time and difficulty details

## Tech Stack

- Next.js
- React
- TypeScript
- CSS

## Getting Started

Install dependencies:

npm install

Start the development server:

npm run dev

Open http://localhost:3000
